# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2026-11-07

### Added
- **Update Notifications**: The app now lets you know right from the taskbar right-click menu and tray whenever a new version is available.
- **Update Details Dialog**: Easily view what's new in the latest version and download it directly with a single click.
- **Check for Updates Button**: You can now check for updates anytime in the Settings window.

### Improved
- **App Icon on Setup Installer**: The Windows setup installer wizard now displays the official Taskbar Lyrics icon instead of the generic installer icon.
- **Fast & Efficient Update Checks**: Update checks now save bandwidth and load previous update details instantly.

## [0.1.0] - 2026-11-07

### Added
- Detects playback and album artwork from Spotify, Apple Music, YouTube, and web browsers.
- Displays live synchronized lyrics line by line with timing offset adjustments.
- Docks directly on your taskbar without stealing window or keyboard focus.
- Dedicated Settings window to customize size, font size, sync offset, and lyric wrapping.
- Draggable overlay bar that automatically remembers your custom taskbar position.
- Right-click tray and overlay menus for fast access to controls, settings, and release notes.
- Offline lyric cache so previously played songs show lyrics without delay.
